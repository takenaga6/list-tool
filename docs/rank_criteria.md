## 理想顧客プロファイル（Offi-Stretch 契約実績ベース）

| 軸 | 内容 |
|---|---|
| **業種** | 情報通信・金融・人材・商社・コンサル・士業等の高利益率B2B |
| **意識** | 社長 or ウェルフェア担当者が健康意識高い |
| **ブランド** | PR媒体に掲載（承認欲求・ブランド意識高い） |
| **福利厚生** | 法定外福利充実だがフィジカルケアは未着手 |
| **規模・拠点** | 自社ビル or 固定オフィス、従業員10〜199名、単一〜少拠点 |

## 判定3段階（重要）

```
process_one_company で実行される判定:

1. pre_screen（軽量NG・HTTPなし）
   → 詳細は agent_screener.md
   
2. check_phase1_must_conditions（Phase 1必須条件・199行目）
   → スクレイピング後・page_text を見て判定
   → 1つでも違反でNG確定
   
3. evaluate_rank_v2（Phase 2 加点減点・804行目）
   → 8点以上=A / 5-7点=B / 1-4点=C / 0点以下=NG（Phase 5 v2.0）
```

### Phase 5 新設加点シグナル（S7〜S10）

```
S7: ISO認定取得 +2点（49社データ 2.42倍差）
   - 判定: ISO番号（ISO9001/14001/27001/45001等）が page_text に含まれる
   - キーワード: ISO_CERT_KEYWORDS（config.py）
   - 除外: 「ISO規格」「ISO基準」「ISOに準じた」等の一般説明語句

S8: SDGs/サステナビリティ宣言 +1点（49社データ 1.84倍差）
   - 判定: SDGs宣言・サステナビリティレポート等の実施を示すキーワード
   - キーワード: SDGS_CERT_KEYWORDS（config.py）
   - 除外: 「カーボンニュートラル」のみは一般表現なので除外対象外

S9: 社長メッセージ内「健康」記載（簡易版）+1点（元データ 2.46倍差だが自動判定限界で減額）
   - 判定: メッセージページURL存在 + 健康キーワードの2条件が必要
   - キーワード: PRESIDENT_MSG_URL_KEYWORDS / PRESIDENT_MSG_HEALTH_KEYWORDS（config.py）
   - 制約: X列（詳細区分）は人間手動判定のため自動化不可。簡易版として実装

S10: 儲かっている業界フラグ（Stage1 +1点 / Stage2 +3点）
   - Stage1（+1点）: PROFITABLE_INDUSTRY_KEYWORDS に業種/ページが該当
   - Stage2（+3点）: Stage1 + 以下のいずれか1つを満たす
     - 従業員数 >= 50名
     - 大手プライム子会社（is_parent_prime_subsidiary）
     - 資本金 >= 1億円（ページ本文に「資本金.{0,10}[1-9][0-9]{8}」を検出）
   - 根拠: 年収B以上3.27倍 + 業界利益率高め2.89倍 + 離職率低め2.56倍 を統合
   - キーワード対象業種: 金融・保険・証券・不動産・IT・コンサル・医療・教育等
```

### 相互作用ボーナス（check_interaction_bonus）

```
以下のいずれか1つが発動時に +3点（重複加算なし）:

3点セット（49社データで継続率100%の組み合わせ）:
- s4_kenko_keiei + s7_iso + s10_profitable  （健康経営×ISO×儲かる業界）
- s4_kenko_keiei + s7_iso + s8_sdgs         （健康経営×ISO×SDGs）
- s4_kenko_keiei + s7_iso + s9_president    （健康経営×ISO×社長健康）
- s7_iso + s9_president + s10_profitable    （ISO×社長健康×儲かる業界）
- s7_iso + s9_president + s3_welfare        （ISO×社長健康×福利厚生）
- s4_kenko_keiei + s8_sdgs + s10_profitable （健康経営×SDGs×儲かる業界）

5シグナル以上保有（シグナル数で判定）:
- s1〜s10 のうち5個以上が TRUE → +3点
```

### 設計ルール（既存・S1〜S6）

```
S1（PR有料媒体掲載）またはS2（健康経営メディア掲載）に該当した時点でBランク確定。
追加シグナル（S3〜S6）が2つ以上あればAランク。
S1/S2なしの場合はS3〜S6の合計で判定（3つ以上でB）。
※ Phase 5 以降は上記ルールより総合スコア（S1〜S10 + ボーナス）で判定。
```

## ✅ Phase 5 実装（2026-05-06）— 49社データ再集計と設計対応

### 正しい集計値（Phase 5 v2.0 で確定）

**旧引き継ぎ情報（2026-04-30）の誤り → Phase 5 v2.0 で訂正済み**

```
【誤り（旧ドキュメント記載）】
- 健康経営認定なしの継続率: 69%
- 健康経営認定ありの継続率: 20%
→「逆相関」と結論していたが、分母に「初回契約中・スポット完了」等を含めた誤集計

【正しい集計（継続中14社 vs 解約済24社 のみで集計）】
- 健康経営認定あり → 継続率 55%
- 健康経営認定なし → 継続率 30%
→ 1.84倍差（正の予測子）= 健康経営認定は「継続率にも良いシグナル」
```

## 自動登録・スキップ閾値

| 条件 | 動作 |
|---|---|
| ランクA（5点以上）かつ 信頼度2以上 かつ 必須フィールド全揃い | 確認モードでも自動登録（HubSpot） |
| ランクC未満 / pending最低条件不足（会社名＋電話or住所） | 候補リストにも出さず自動スキップ |

### 自動登録の必須フィールド（has_auto_fields）

| フィールド | 理由 |
|---|---|
| 会社名 | 登録の基本単位 |
| 企業URL | 重複チェック・HubSpotのドメイン紐付け |
| 電話番号 | テレアポ必須 |
| 従業員数 | ターゲット規模の確認（10〜199名） |
